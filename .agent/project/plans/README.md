# 📋 CareBank Phase Plans

> **Dedicated directory for phase-by-phase implementation plans.**

## Structure

```
plans/
├── backend/     # Backend phase plans (carebank-backend)
└── frontend/    # Frontend phase plans (carebank-frontend)
```

## Naming Convention

`PLAN-phase{N}-{slug}.md` — e.g., `PLAN-phase1-infrastructure.md`

## Usage

Before starting any phase, check if a plan exists here. Plans are created during the `/plan` workflow and reviewed before implementation begins.
