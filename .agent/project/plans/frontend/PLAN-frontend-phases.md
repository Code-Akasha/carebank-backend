# PLAN: Frontend MVP Phases

## Goal
Implement the CareBank frontend (React + Vite + TailwindCSS) integrating with the Phase 1-6 backend features, achieving all 3 "killer features": Health Score, What-If Simulator, and Auto-Savings.

## Constraints & Rules
- Must use existing tech stack configured in Phase 1 (Vite, React, TailwindCSS).
- Must adhere to frontend design principles defined in `@frontend-specialist`.
- Must merge feature branches to `develop` via PRs.

---

## Phase 1: Foundation (Vite + Routing)
*(Completed)*
- Project initialization with Vite, React, TailwindCSS.
- Basic routing (Dashboard, Simulator, Products).
- Static Health Score Meter component.

## Phase 5: Core UI Integration
*(Parallel with Backend Phase 5)*

**Branch:** `feature/api-integration`
- **Task 1: API Client Layer**
  - Setup Axios/fetch interceptors or a unified API service class.
  - Implement error handling parsing structure for Coordinator Agent outputs.
  - Implement loading and skeleton states.
- **Task 2: Dashboard Data Binding**
  - Connect Health Score meter to `/api/health-score/{user_id}`.
  - Fetch user transactions and highlight anomalies based on backend flags.
  - Implement notification center for auto-savings and opportunity nudges.
- **Task 3: Simulator UI Binding**
  - Create the What-If input form (expense amount, category).
  - Post to `/api/simulate` and render dual-forecast charts (Current vs Simulated).
  - Display product recommendations based on risk scores.
- **Task 4: Auto-Savings Approval UI**
  - Implement the "Accept/Decline" cards for micro-savings.
  - Render impact explanations generated by the Communication Agent.

## Phase 6: Polish & Demo Readiness
*(Parallel with Backend Phase 6)*

**Branch:** `feature/ui-polish`
- **Task 1: Micro-Interactions**
  - Add smooth transitions to the Health Score meter changes.
  - Add hover states and tooltips to transaction anomaly flags.
- **Task 2: Responsive Design**
  - Verify mobile viewport layouts for Dashboard and Simulator.
- **Task 3: Error Boundaries**
  - Implement full-page and component-level error states (e.g., if backend is unreachable).
- **Task 4: Demo Script Prep**
  - Work with backend to ensure the 3-minute demo flow can be executed flawlessly from the UI.

---

## Verification Plan
1. **API Mocks:** Run UI tests with mocked backend responses before final integration.
2. **E2E Flow:** Verify user can navigate from Dashboard (Health Score) -> Simulator -> View Product Recommendations.
3. **Responsive Check:** Lighthouse UI checks for mobile accessibility and Core Web Vitals.
